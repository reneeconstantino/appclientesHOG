BRUMA · CÓMO SUBIR LA APP (2 pasos)
====================================

Tu repositorio de GitHub está VACÍO (fue recreado), así que este paquete
sube el proyecto completo desde cero con un solo script.

REQUISITO: tener Git instalado → https://git-scm.com/downloads
(En Windows, durante la instalación deja todo en "Next" con los valores default.)

PASO 1 · SUBIR A GITHUB
-----------------------
· WINDOWS: doble clic en  SUBIR-CAMBIOS.bat
· MAC:     abre Terminal, escribe  bash  (con espacio al final),
           arrastra el archivo SUBIR-CAMBIOS.sh a la ventana y presiona Enter.

La primera vez, Git te pedirá iniciar sesión en GitHub:
· Si se abre el navegador → autoriza y listo (lo normal en Windows/Mac modernos).
· Si te pide usuario y contraseña en la terminal:
    - Usuario: reneeconstantino
    - Contraseña: NO es tu contraseña; es un token. Créalo en
      github.com/settings/tokens → "Generate new token (classic)" →
      marca la casilla "repo" → Generate → copia el token y pégalo.

Al terminar verás: "Listo. Vercel..." y tu repo en GitHub tendrá
las carpetas app/, components/, lib/, types/ y los archivos de config.

PASO 2 · RECONECTAR VERCEL (obligatorio, 1 minuto)
--------------------------------------------------
Como el repo se recreó, Vercel perdió el enlace ("repository can't be found").
1. vercel.com → tu proyecto → Settings → Git
2. Si aparece un repo conectado con error: "Disconnect".
3. "Connect Git Repository" → elige reneeconstantino/appclientesHOG.
4. Desde ese momento, CADA push a main deploya solo.
   (El push del Paso 1 quizá no disparó deploy si Vercel aún no estaba
   conectado: en ese caso ve a Deployments → "Create Deployment" o haz
   Redeploy; ahora sí encontrará el repo.)
